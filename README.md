# SmartPool

Diseño 3D de albercas, jardines y cotizaciones, directo en el navegador.

**Abrir la app:** https://sinaloa69522-cmd.github.io/SmartPool/

## Instalar en la computadora
- **Chrome:** abre el link, y en la barra de direcciones haz clic en el ícono de instalar (o menú ⋮ → *Transmitir, guardar y compartir* → *Instalar página como app*).
- **Edge:** menú ⋯ → *Aplicaciones* → *Instalar este sitio como aplicación*.

Queda con su propio ícono en el escritorio y el menú de inicio. Después de abrirla una vez con internet, también funciona sin conexión.

## Archivos
- `index.html`: la app completa.
- `manifest.webmanifest`, `sw.js`, `icons/`: lo necesario para instalarla como app.
